# AI Key 管家

管理各家 AI 厂商 API key 的本地小工具。双击就能用，key 加密保存在自己电脑上。

很多人在 DeepSeek、Kimi、通义、智谱、豆包、硅基流动……都注册过、生成过 key，时间一长就忘了哪个 key 在哪、还能不能用、还剩多少钱。AI Key 管家把它们集中到一个地方：

- **扫描电脑找回**：自动找出散落在配置文件、项目 `.env`、系统环境变量、CC Switch / Cherry Studio 等工具配置里的 key（只读，不改任何文件）
- **自动识别厂商**：根据 key 的格式和所在位置判断是哪家的
- **一键检测**：检测 key 是否还有效，能查余额的直接显示余额
- **到期提醒**：设置到期日，快到期和已失效的 key 会排在最前面
- **一键复制**：复制 key、复制接口地址（Base URL）、直达厂商控制台

## 安全

- 所有 key 用主密码加密（PBKDF2-SHA256 60 万次 + AES-256-GCM），只保存在本机，不上传到任何服务器
- 主密码不保存在任何地方；忘了主密码就无法打开（没有后门）
- 检测余额时，key 只发给对应厂商的官方接口
- 界面运行在 `127.0.0.1`，只有本机能访问；每次启动生成随机令牌，其他网页无法调用
- 15 分钟没有操作自动锁定

保险箱文件位置：
- Windows：`%APPDATA%\AIKeyVault\vault.json`
- macOS：`~/Library/Application Support/AIKeyVault/vault.json`

## 使用

**Windows**：双击 `AI-Key管家.exe`。第一次运行如果出现蓝色的「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（程序没有付费签名，所以会有这个提示）。

**macOS**：双击 `AI-Key管家-mac`。如果提示「无法验证开发者」，在文件上右键 →「打开」→「打开」。

运行后会自动在浏览器里打开管理页面。用完关掉那个黑色的命令行窗口即可退出。

## 支持的厂商

| 厂商 | 自动识别 | 检测有效 | 查余额 |
|---|---|---|---|
| DeepSeek | ✅ | ✅ | ✅ |
| Kimi / 月之暗面 | ✅ | ✅ | ✅ |
| 硅基流动 | ✅ | ✅ | ✅ |
| OpenRouter | ✅ | ✅ | ✅ |
| 阿里百炼 / 通义千问 | ✅ | ✅ | 控制台查看 |
| 阶跃星辰 | ✅ | ✅ | 控制台查看 |
| OpenAI / Anthropic / Gemini / Groq / xAI | ✅ | ✅ | 控制台查看 |
| 智谱 GLM / 火山方舟 / MiniMax / 腾讯混元 / 百度千帆 / 百川 | ✅ | — | 控制台查看 |

DeepSeek、通义、混元、阶跃的 key 格式一样（`sk-` + 32 位），扫描时会根据所在文件里的变量名、网址判断；判断不了的，检测时会依次尝试，哪家返回有效就归到哪家。

## 从源码构建

需要 Go 1.24+，没有任何第三方依赖。

```bash
# Windows
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o AI-Key管家.exe .
# macOS (Apple 芯片)
GOOS=darwin GOARCH=arm64 go build -ldflags="-s -w" -o AI-Key管家-mac .
```
